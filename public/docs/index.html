API Kulsh

Единый интерфейс к моделям Kulsh. Один ключ, один общий лимит и баланс — как в веб-чате.

key

API работает. Ключ создаётся в аккаунте — открой меню аккаунта (аватар в правом верхнем углу) → API. Один ключ подходит и для API, и для веб-чата.

Обзор

API принимает сообщения и возвращает ответ модели потоком (Server-Sent Events). Формат совместим с распространённой схемой чат-комплишенов, поэтому подключается обычным HTTP-клиентом.

  • Базовый адрес: https://kulsh.vercel.app/api/v1
  • Формат: JSON, ответ — поток событий text/event-stream
  • Аутентификация: заголовок Authorization: Bearer <API_KEY>
extension

[OI]-совместимость. Для IDE и клиентов есть POST /api/v1/chat/completions (или POST /v1/chat/completions) с обычными choices[].delta.content и data: [DONE], а также GET /api/v1/models в формате {"object":"list","data":[...]}. Поддерживаются stream: true и stream: false. Базовый URL для таких клиентов: https://kulsh.vercel.app/v1, ключ — тот же kulsh_sk_....

Пример [OI]-совместимого запроса

# curl
curl https://kulsh.vercel.app/v1/chat/completions \
  -H "Authorization: Bearer $KULSH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-v4.1-flash","stream":true,"messages":[{"role":"user","content":"привет"}]}'

Аутентификация

Ключ создаётся в аккаунте Kulsh. Один ключ работает и для веб-чата, и для API, а расход идёт с общего баланса и бесплатного лимита.

# пример заголовка
Authorization: Bearer kulsh_sk_...

POST /v1/chat

POST/api/v1/chat

Отправляет историю сообщений и стримит ответ.

Тело запроса

{
  "model": "deepseek-v4.1-flash",
  "messages": [
    { "role": "user", "content": "Привет, Кульш!" }
  ],
  "temperature": 0.9,
  "stream": true
}

Ответ (поток)

data: {"delta":"Привет!"}
data: {"delta":" Чем помочь?"}
data: {"done":true,"usage":{"used":12430,"limit":100000,"unit":"tokens"}}

Модели

GET/api/v1/models

Возвращает доступные модели и их множитель расхода дневного лимита.

{
  "models": [
    { "id": "gemini-3.5-flash", "provider": "google", "vision": true, "mult": 1.5 },
    { "id": "deepseek-v4.1-flash", "provider": "neutralbeats", "vision": true, "mult": 1 },
    { "id": "deepseek-v4-pro", "provider": "neutralbeats", "vision": false, "mult": 2 },
    { "id": "glm-5.3-flash", "provider": "neutralbeats", "vision": true, "mult": 1 },
    { "id": "kimi-k3", "provider": "neutralbeats", "vision": true, "mult": 3 }
  ]
}

Лимиты и usage

У каждого аккаунта один дневной лимит, измеряемый в токенах. Каждая модель тратит его по-разному: лёгкие — почти ничего, флагманы — заметно больше.

GET/api/v1/usage
{
  "used": 12430,
  "limit": 100000,
  "unit": "tokens",
  "resetsAt": "2026-10-11T00:00:00Z",
  "balance": 0
}
info

Если ответ не пришёл по технической причине на стороне сервиса — токены не списываются.

Ошибки

{ "error": "limit_exceeded", "message": "Дневной лимит исчерпан" }
  • 401 — ключ отсутствует или недействителен
  • 402 — исчерпан бесплатный лимит и нулевой баланс
  • 400 — некорректный запрос (нет сообщений, вложение не поддерживается)
  • 502 — модель временно недоступна (токены не списываются)
  • 503 — на сервере не заданы ключи провайдеров
